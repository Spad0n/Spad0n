# Oh hello there! 👋

Final-year Software Engineering student in France, doing a lot of systems programming on the side.

I like understanding how things work under the hood, and using that knowledge to write performant programs — especially when it comes to architecture-level details (x64, ARM, etc).

Native French speaker (obviously 🇫🇷), also speak Spanish and Swedish.

## What I'm working on lately

**[mipsim](https://github.com/Spad0n/mipsim)** — a MIPS32 virtual machine written in C, with the lexer/parser in C++ (no STL) · [try it in your browser](https://spad0n.github.io/mipsim/)

**[wvk](https://github.com/Spad0n/wvk)** — a minimal Vulkan wrapper for experimenting with modern rendering techniques

**[Insula](https://github.com/Spad0n/insula)** — a modular framework for game development and graphical applications
